2. Codex stalls. Reuse timestamped native turn/tool/lifecycle evidence. Report observed silent gaps and hook wake-ups with start/end/type/source references. Unknown lifecycle/coverage remains PARTIAL or field UNSUPPORTED with reason. Count a linked follow-up admitted after the parent's acceptance and within7days as a rework episode; retain existing fix-commit/reaccept companion counts without double-counting an episode. A follow-up outside the window is listed outside coverage, not silently mixed. Accepted parent artifacts and original logs stay immutable. Add a documented retrospective link for known lane59b to lane59 only with explicit evidence; this is a data annotation, not a rewritten acceptance.
4. Token definition. Define processed tokens as uncached input + cache read + cache creation + output, counted once per native request. Claude categories are disjoint. Codex input already includes cached input, so use input+output, reporting cached as a subset; reasoning output is a subset of output, never added again. Top-tier filtering uses the existing shared model-tier rules; model unknown remains unknown. State the same definition and scope in baseline and current census, including deduplication, windows, omitted/missing sessions and cache behavior. Recompute baseline from its source evidence if its actual definition differs; never relabel incompatible historical numbers as comparable. Missing source keeps the comparison explicitly unavailable.
