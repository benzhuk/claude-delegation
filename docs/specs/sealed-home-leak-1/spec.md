## Lane 24, sealed-home-leak: the sealed test home never outlives its suite

Lead: skills-n (Netcup, where 585 leaked directories filled inodes to 70 percent before Ben approved their deletion on 2026-09-27, 10:46 AM NY). Territory: `scripts/test-home.mjs`, `scripts/test-home.test.mjs`, `scripts/run-tests.mjs`, `scripts/run-tests.test.mjs` if it exists.

Defect: `test-home.mjs:52` creates `sealed-home-*` under the OS temp dir; `run-tests.mjs:101-106` cleans up in a `finally` that keeps a FAILED suite's home on purpose (RT-18/F6) and never runs when the suite is killed (SIGINT, SIGTERM, a pane closed, an ssh session dropped).

Pinned design: (1) `makeTempHome` registers its directory in a per-process list and installs, once per process, one handler each for `exit`, `SIGINT`, `SIGTERM` and (off win32) `SIGHUP` that removes every still-registered directory synchronously and then re-raises: remove its own listeners, then `process.kill(process.pid, signal)`, giving exit code 128+n on POSIX. `makeTempHome` returns a `keep()` (alias `unregister()`) that removes the directory from the list; `run-tests.mjs` calls it on a non-zero suite result so the keep-on-failure behaviour is unchanged. (2) `run-tests.mjs` sweeps, at start, every `sealed-home-*` directly under the temp dir whose mtime is older than 6 hours, prints one line `swept n stale sealed homes`, and skips the sweep when `~/.agents/ws-off-sweep` or the shared `~/.agents/ws-off` exists (kill switch; a sweep error is printed and the suite runs anyway). Never anything younger than 6 hours (another suite on this host may own it), never a name that does not match the exact prefix. `--no-sweep` for the sweep's own tests. On win32 the sweep is the guarantee: `child.kill('SIGTERM')` terminates a Windows process without running handlers, so the signal test is skipped there with that reason stated in the test.

Acceptance: unit tests: a child node process that makes a temp home and is killed with SIGTERM leaves no directory (POSIX only, skipped on win32 with reason); a failing suite keeps its home; a passing suite removes it; the sweep removes old, keeps young, keeps non-matching, honours both kill switches; registration is idempotent (one listener per event after two homes). Live proof on Netcup in the record: `ls -d /tmp/sealed-home* 2>/dev/null | wc -l` before and after one suite run. Sealed suite green on a second host.
