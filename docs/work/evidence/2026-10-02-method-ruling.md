## Verdict: adopt problem-led bets, with four amendments. Most of the current plan stops.

The synthesis passes Ben's test where the card never did. It puts the problem statement in Ben's hands and nothing else; it makes a blank-page design by a fresh judge a routine step of every planning turn, so throwing the architecture out is no longer heroic; it names classes of failure from a log of real misfits instead of fixing instances; it puts a fixed appetite on every bet, which is the brake on a system whose every turn wants to merge a lane; and it retires the rule that produced the castle, "change only what improves one of the four measures", which every patch can satisfy and almost no deletion can. The literature behind it is experience reports, not controlled studies, and the synthesis says so; the measures report's "smallest set" and the process report's "no controlled evidence" were checked and are quoted correctly.

### Amendment 1: no code first
The method is four markdown files (PROBLEM.md, the misfit log, bet records, decision records) and a planning turn run by hand. The eight mechanical checks in synthesis section 3 are not built until a misfit line shows one is needed, and then one at a time. The reason is the card's own history: "a rule no script checks" pushed this project to write scripts for every rule, and the scripts became the castle. The first two planning turns run with no new code at all.

### Amendment 2: the harness may be deleted
Open question 4 is answered yes. The planning turn may conclude that most of this repository should go and that stock Claude Code plus Codex with a few files does the job. If that option is not live, the blank-page design is theater.

### Amendment 3: the blank-page designer alternates
The fresh judge that writes the blank-page design alternates between a fresh Claude session and a Codex session, and reads only PROBLEM.md and the misfit log. Freshness alone does not guarantee a different frame; model diversity is the cheapest hedge the synthesis names and it is untested, so it is tried, not assumed.

### Amendment 4: first PROBLEM.md from Ben's own words
The lead drafts the first PROBLEM.md from Ben's three statements of 10/2 and his quotes in history, in one page, and Ben edits it. Scope: his general pattern, "every complex system I have tried to build with LLM agents", with this harness as the first instance worked on. That keeps the problem his and does not make him write from a blank page at 10 in the morning.
