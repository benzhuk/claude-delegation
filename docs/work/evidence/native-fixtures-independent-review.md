Rejected or narrowed claims
1. Both original SSE send functions emitted literal backslash-n characters. Original successful summaries show stream:true followed by stream:false for each completed Messages exchange. Native Stop behavior was real, but the original endpoint claim hid a non-streaming fallback. Corrected fixtures replace the framing with actual newline characters and reproduce the behavior without fallback.
2. The original completion stdout/event split uses a valid single escaped newline in source; the split itself is not a defect. The double escape in the generated hook template is also appropriate because it produces a single escaped newline in the generated JavaScript. Do not blanket-replace all escaped newlines.
3. Original episode readFile(...).slice(-65536) reads the entire file and slices characters, not bytes. Its bounded_bytes value cannot establish bounded IO. That claim is rejected; corrected fixture uses positioned byte reads.
4. Original child.kill('SIGINT') does not prove that the Claude native cancellation handler, TUI interrupt path, or SDK interrupt protocol ran. On Windows this subprocess-kill test is insufficient evidence of graceful/native cancellation; a close event labeled SIGINT is not an interrupt acknowledgement. Absence of Stop after terminating the process only establishes absence before process death. It says nothing about async hook work already launched, queued continuation, cancellation revocation, or prompt replacement. Corrected completion fixture skips that test explicitly.
5. Original environment spreads all process.env entries. Consequently the claim that no inherited live credentials or provider-routing environment could influence execution is not justified by source alone. Corrected fixture allows only basic executable/Windows/temp environment keys, sets disposable config/home/userprofile/agents directories, supplies a synthetic key and loopback base URL, disables nonessential traffic, and retains --setting-sources empty. No provider is contacted by the fixture server, and all observed Messages requests target loopback. This is not a network-level proof of zero unrelated native traffic.
6. The episode result demonstrates structural identity for the tested print/resume path only. It does not prove an activation capture protocol, atomic state transition, authentic user cancellation, missed-hook recovery, branch changes, truncation behavior, TUI behavior, or stale callback rejection. A bounded tail may legitimately have no true-user UUID; that must fail closed.

Original reports, fixtures, and prior saved summaries are preserved unchanged. Reruns wrote only new temporary files/directories.
