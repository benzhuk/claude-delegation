+## Phase 3: false-positive narrowing (lane 70, 2026-10-04)
+
+Six refusals seen on synthetic text (a heredoc appending test code, a report
+heredoc, a `...process.env` spread, a script summing census JSON, a
+`chezmoi status | grep` filter, a markdown brief) were narrowed. Each fix
+makes the named false positive pass and leaves every earlier deny in the
+self-test corpus intact; each has a near-miss twin in the self-test's "LANE 70
+corpus" section that must keep denying.
+
+- **Sourcing check** (`has_source_sourcing`): `source` / `.` must now sit at a
+  command position (start of text, after `; & | ( { `` ` `` `, a quote, or a
+  shell keyword such as `then`/`do`/`exec`). A sentence period after a
+  paren, quote or `...` no longer reads as a dot-source.
+- **`.key` property access** (`strip_key_property_access`): `n.key === x` and
+  `(n) => n.key` style access is no longer taken for a private key file name.
+  A key file operand (`cat a.key`, `scp h:a.key`, `--key=a.key`, `$(cat a.key)`,
+  `{a.key,b.key}`) keeps denying.
+- **Quoted `cat > file` heredocs** (`strip_quoted_heredoc_bodies`): the
+  command-substitution bailout now looks at the text left after the exempt
+  bodies are blanked, so backticks and `${...}` inside a markdown or JS body no
+  longer defeat the exemption. A substitution outside an exempt body, or an
+  executed (interpreter) body, still bails.
+- **Environment pass-along** (`strip_env_passalong`): `{ ...process.env }`,
+  `env: process.env`, Python `**os.environ` and `env=os.environ` are not a dump
+  unless the text also prints the environment (`has_secret_print_context`).
+- **grep filters** (`strip_search_pattern_arguments`): a pattern quoted one
+  level deeper (an `ssh "...grep -E \"x\"..."` string) and an unquoted first
+  pattern argument without `-f` are search patterns, not file operands.
+- **Written prose** (Write/Edit): content scanning for an embedded secret-file
+  read is skipped when the target AND its symlink-resolved path end in `.md`,
+  `.markdown`, `.mdx`, `.txt` or `.rst`. Any other extension, a secret-file
+  target path, and a key-shaped literal are checked exactly as before.
+
+Accepted residual: a `{ ...process.env }` copy written to a file without any
+print verb in the same statement is no longer denied (the dump to a transcript
+is what this hook guards, and a later read of that file is not a secret path).
